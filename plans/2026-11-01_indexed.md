# Indexed price comparison (#4)

1. Download adjusted AAPL/MSFT/NVDA closes for one year and align complete
   trading days. Missing series stop the run instead of silently disappearing.
2. Index each series to 100 at the shared first close. Use the existing dark
   CI, fixed ticker colors and German month labels. Separate end labels in
   display coordinates, keeping dots at the true values.
3. Run the script, inspect its PNG, check the arithmetic and the 15-point
   label gap with synthetic data, then run Black and Ruff.

The integration branch was absent and is initialized from main. This is an
interactive implementation session; no Claude-specific fallback automation
or external session relay is started.
