Corporate Identity für Portfolio-Projekte · Vorschlag vom 1. November 2026

Eine Schrift, eine Leitfarbe, eine geprüfte Datenpalette. Alles steckt in einer JSON-Datei, aus der Matplotlib, Plotly und Streamlit ihre Werte lesen, damit Anschreiben, Lebenslauf und Dashboards wie aus einem Guss wirken.

Century Gothic

Die Schrift aus Anschreiben und Lebenslauf. Im Web und auf Streamlit Cloud springt Questrial ein, die frei verfügbare, sehr ähnliche geometrische Schrift.

Waldgrün #2E5A2E

Die Farbe der Trennlinien in deinen Bewerbungsunterlagen. Sie wird zur Leitfarbe für Überschriften, Linien und Links, und Slot 1 der Datenpalette ist ihre aufgehellte Variante.

Geprüfte Datenfarben

Sieben Kategorienfarben in fester Reihenfolge, für helle und dunkle Darstellung getrennt abgestimmt und auf Rot-Grün-Schwäche sowie Kontrast geprüft.

Typografie

Century Gothic ist lizenzpflichtig (Monotype, mit MS Office installiert). Für alles, was im Browser läuft, gilt der Stack 'Century Gothic', 'Questrial', sans-serif: Wer Office hat, sieht das Original, alle anderen Questrial. Die Schrift hat nur einen Schnitt, deshalb entsteht Hierarchie über Größe, Versalien mit Sperrung und die grüne Linie statt über Fettdruck.

Kategorienfarben für Diagramme

Immer in dieser Reihenfolge vergeben, nie zyklisch wiederholen. Eine Aktie behält ihre Farbe in jedem Diagramm (ORCL ist immer Slot 1, MSFT Slot 2, MCD Slot 3). Benachbarte Farben haben unter simulierter Rot-Grün-Schwäche einen Abstand von mindestens ΔE 10 (Ziel 8). Für Streudiagramme und Karten höchstens die ersten drei verwenden.

Grün und Rot sind an der Börse Konvention, für Menschen mit Rot-Grün-Schwäche aber schwer zu trennen. Deshalb trägt die Farbe nie allein: Dreieck, Vorzeichen und hohle oder gefüllte Kerzen sagen dasselbe. Für eine barrierearme Variante liegt Blau/Kupfer in der JSON.

Sobald die Streaming-Pipeline läuft

  • Live-Ticker: Trades pro Sekunde je Symbol als Linie über die letzten 15 Minuten, mit hervorgehobenem letzten Punkt.
  • Fenster-Aggregate: 1-Minuten-Kerzen direkt aus den Spark-Fenstern, gleiche Darstellung wie oben.
  • Pipeline-Gesundheit: Kafka-Consumer-Lag und Verarbeitungszeit als Kennzahlen mit Statusfarbe, Symbol und Text.
  • Datenqualität: Lücken pro Symbol und Stunde als sequenzielle Heatmap in Waldgrün.
Umsetzung

Die JSON ist die einzige Quelle für alle Werte. Mein Vorschlag: Sie liegt in jedem Portfolio-Repo unter style/felix-schramm-ci.json, ein kleines Modul lädt sie für Matplotlib und Plotly. Das NOW-Dashboard zur Ladeinfrastruktur behält bewusst die NOW-Farben, weil es für eine konkrete Bewerbung im Design des Arbeitgebers gebaut ist.

style/ci.py · Matplotlib und Plotly

      
"""Load the personal CI tokens and apply them to Matplotlib and Plotly."""

import json
from pathlib import Path

import matplotlib.pyplot as plt
import plotly.graph_objects as go
import plotly.io as pio
from cycler import cycler

CI = json.loads((Path(__file__).parent / "felix-schramm-ci.json").read_text())
COLORS = [c["hex"] for c in CI["color"]["categorical"]["light"]]
NEUTRAL = CI["color"]["neutral"]["light"]
FONT = CI["typography"]["font_family"]


def use_matplotlib():
    """Set rcParams to the CI look (left title, y-grid only, no frame).

    :return: None
    """
    plt.rcParams.update({
        "font.family": FONT["stack_matplotlib"],
        "axes.prop_cycle": cycler(color=COLORS),
        "axes.titlelocation": "left",
        "axes.titlesize": 13,
        "axes.labelcolor": NEUTRAL["ink_secondary"],
        "axes.edgecolor": NEUTRAL["axis"],
        "axes.spines.top": False,
        "axes.spines.right": False,
        "axes.spines.left": False,
        "axes.grid": True,
        "axes.grid.axis": "y",
        "grid.color": NEUTRAL["gridline"],
        "xtick.color": NEUTRAL["ink_muted"],
        "ytick.color": NEUTRAL["ink_muted"],
        "figure.facecolor": NEUTRAL["surface"],
        "axes.facecolor": NEUTRAL["surface"],
        "text.color": NEUTRAL["ink"],
        "lines.linewidth": 2,
        "legend.frameon": False,
    })


def use_plotly():
    """Register the CI as Plotly template "felix" and make it the default.

    :return: None
    """
    pio.templates["felix"] = go.layout.Template(layout={
        "font": {"family": FONT["stack_css"], "color": NEUTRAL["ink"]},
        "colorway": COLORS,
        "paper_bgcolor": NEUTRAL["surface"],
        "plot_bgcolor": NEUTRAL["surface"],
        "title": {"x": 0, "xanchor": "left"},
        "xaxis": {"showgrid": False, "linecolor": NEUTRAL["axis"]},
        "yaxis": {"gridcolor": NEUTRAL["gridline"], "zeroline": False},
        "legend": {"orientation": "h", "x": 0, "y": 1.08},
    })
    pio.templates.default = "felix"
